### HealthBud — Predictive Healthcare Alert Engine

Heart-disease prediction REST API using a Random Forest Classifier, with Redis Pub/Sub for asynchronous alert queuing and MongoDB indexing for low-latency record retrieval.

| Layer | Technology |

| Machine Learning | Scikit-learn, Random Forest |
| Database | MongoDB |
